# PRD-11 Coach (explainable hints) + auto notes — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When a player is stuck, Nine names the technique that applies, lights the exact cells, and says one true sentence about why — and a wand fills every legal pencil mark in one undoable move.

**Architecture:** The engine already knows everything (`LogicSolver.nextStep` returns technique + cells + digit + effects). This PR adds a thin `CoachAdvice` seam over it in `Sources/Engine/Coach.swift`, turns that into sentences inside the existing `BoardSpeech` phrasebook in `Sources/Shared`, and renders it through one new `BoardView` parameter (`CoachFocus`) plus a new `Sources/App/CoachCard.swift`. Auto notes is a bulk `NineGame` mutation that reuses the existing `NineMove.previousPencil` array rather than adding a persisted enum case.

**Tech Stack:** Swift 6, SwiftUI, XCTest, SwiftPM (`NineEngine` + `NineShared` targets, Linux-clean), XcodeGen for the app targets.

**Design doc:** [`docs/superpowers/specs/2026-07-25-prd-11-coach-design.md`](../specs/2026-07-25-prd-11-coach-design.md)

## Global Constraints

- **Working directory is `nine/`** for all `swift test` and `xcodebuild` commands. The repo root is one level up.
- **Never add a field to `SolveStep`, `GeneratedPuzzle`, or `LibraryEntry`.** The first two sit inside the golden-corpus SHA-256; the third is erased by older builds' autosave. New state takes a sibling type or a sibling top-level key. (`nine/docs/EXECUTING-A-PRD.md` §2, §3)
- **Never add a case to `NineMove.Kind` or `LoggedMove.Kind`.** Both are decoded non-tolerantly by builds already on TestFlight (450/451/452); an unknown raw value throws and loses the board.
- **Do not modify `Sources/Engine/Sudoku.swift` or `Sources/Engine/BacktrackSolver.swift`.** PRD-23 froze them byte-identical to `origin/main`; they define classic dailies forever.
- **`Sources/App`, `Sources/Widgets` and `Sources/Shared` may not contain the strings** `VariantChannel`, `VariantGenerator`, `VariantPuzzle`, `VariantConstraint`, `VariantTier`, `VariantBand`, `ConstraintContext`, `ConstraintBacktrackSolver`, `CageTiling`. `VariantChannelSealTests` greps for them line by line and fails the build. Use defaulted parameters so the app never names `ConstraintContext`.
- **Every user-facing string goes in the one `private enum Phrase` block at the bottom of its own file.** No English literals in logic or view code. This is PRD-20's only seam.
- **The coach may never read `puzzle.solution`.** Everything it says must be derivable from what is on the player's screen, so it speaks identically with `errorHighlight` on and off.
- **Run the golden corpus after every engine commit:** `swift test --filter GoldenCorpus`. A mismatch is a bug until proven otherwise.
- **`swift test` budget is ~120 s and currently reads ~112.5 s.** New tests must be cheap — reuse the `PuzzleGenerator.generate(seed: 1, difficulty: .gentle)` fixture in `setUp`, never generate inside a loop.

## Task 1: Engine — `CoachAdvice` and honest contradiction detection

**Files:**
- Create: `nine/Sources/Engine/Coach.swift`

**Interfaces:**
- Consumes: `SolveStep`, `Technique`, `CandidateState`, `LogicSolver.nextStep(in:allowed:)`, `SudokuGrid`, `Sudoku` (all existing).
- Produces, for Tasks 2, 3 and 5:
  - `public enum CoachAdvice: Sendable, Equatable { case step(CoachStep); case contradiction(cells: [Int]); case exhausted; case solved }`
  - `public struct CoachStep: Sendable, Equatable { public let step: SolveStep; public let patternUnit: Int?; public let targetUnit: Int? }`
  - `public static func LogicSolver.advice(for grid: SudokuGrid, allowed: [Technique] = allTechniques, context: ConstraintContext = .classic) -> CoachAdvice`
  - `public var SudokuGrid.conflictingCells: [Int]`
  - `public var CandidateState.deadCells: [Int]`

**Why `CoachStep` wraps `SolveStep` instead of extending it:** `SolveStep` is
stored in `GeneratedPuzzle.steps`, which is inside the golden-corpus hash. A new
field would move all 56 frozen hashes for a value that is nil on every existing
board. This is the same sibling-type rule `VariantPuzzle` and `nine.history`'s
`band` key already follow.

**Unit indices** are the convention `Sudoku.units` already fixes: `0..<9` rows,
`9..<18` columns, `18..<27` boxes. Task 2 reads them without engine state.

```swift
import CouchCore

final class CoachTests: XCTestCase {

    /// A grid with one empty cell whose row, column and box already hold the
    /// other eight digits — the textbook naked single.

        var grid = solved
        grid[40] = 0

    // MARK: - Advice selection

    func testNakedSingleIsOfferedForASingleHole() {
        guard case .step(let coach) = LogicSolver.advice(for: gridWithOneHole()) else {
            return XCTFail("a one-hole grid must yield a step")
        }
        XCTAssertEqual(coach.step.technique, .nakedSingle)
        XCTAssertEqual(coach.step.placement?.cell, 40)
        XCTAssertNil(coach.patternUnit, "a naked single is cell-scoped, not unit-scoped")
        XCTAssertNil(coach.targetUnit, "a naked single eliminates nothing")
    }

    func testFullConsistentGridIsSolved() {
        let solved = PuzzleGenerator.generate(seed: 1, difficulty: .gentle).solution
        XCTAssertEqual(LogicSolver.advice(for: solved), .solved)
    }

    // MARK: - Contradiction: pure logic, never the solution

    func testPeerClashIsReportedAndBeatsAnyStep() {
        // Two 7s in row 0. Both are flagged; neither is looked up in a solution.
        var grid = SudokuGrid()
        grid[0] = 7
        grid[5] = 7
        guard case .contradiction(let cells) = LogicSolver.advice(for: grid) else {
            return XCTFail("duplicate peers must read as a contradiction")
        }
        XCTAssertEqual(cells, [0, 5])
    }

    func testDeadCellIsReportedWhenNoPeerClashExists() {
        // Cell 0's row holds 1...8 and its column holds the 9. Nothing can go
        // in cell 0, and no two filled cells clash — so this is a contradiction
        // that only the candidate pass can see.
        var grid = SudokuGrid()
        for column in 1...8 { grid[column] = column }   // row 0 gets 1...8
        grid[9] = 9                                     // row 1, column 0 gets the 9
        XCTAssertTrue(grid.conflictingCells.isEmpty, "no digit repeats in any unit")
        guard case .contradiction(let cells) = LogicSolver.advice(for: grid) else {
            return XCTFail("a dead cell must read as a contradiction")
        }
        XCTAssertEqual(cells, [0], "cell 0 is the one with no candidates left")
    }

    func testContradictionIsCheckedBeforeAnyStepIsOffered() {
        var grid = PuzzleGenerator.generate(seed: 1, difficulty: .gentle).puzzle
        // Drop a digit that duplicates a peer, on a board that otherwise has
        // plenty of legal singles available.
        let filled = (0..<81).first { grid[$0] != 0 }!
        let peer = Sudoku.peers[filled].first { grid[$0] == 0 }!
        grid[peer] = grid[filled]
        guard case .contradiction = LogicSolver.advice(for: grid) else {
            return XCTFail("a contradictory board must never be handed a step")
        }
    }

    // MARK: - The band ceiling

    func testAdviceNeverExceedsTheAllowedTechniques() {
        let puzzle = PuzzleGenerator.generate(seed: 7, difficulty: .sharp)
        var seen: Set<Technique> = []
        var grid = puzzle.puzzle
        // Walk the board with a Gentle ceiling and record everything offered.
        for _ in 0..<200 {
            guard case .step(let coach) = LogicSolver.advice(
                for: grid, allowed: Difficulty.gentle.allowedTechniques
            ) else { break }
            seen.insert(coach.step.technique)
            guard let placement = coach.step.placement else { break }
            grid[placement.cell] = placement.digit
        }
        XCTAssertTrue(
            seen.isSubset(of: Set(Difficulty.gentle.allowedTechniques)),
            "a Gentle board must never be lectured about \(seen)"
        )
    }
}
```

```swift
// Coach.swift — the seam between the solver and the teacher (PRD-11).
//
// `LogicSolver.nextStep` has returned technique + cells + digit + effect since
// 1.0; what was missing was a caller that could ask the question safely. Two
// rules shape everything here:
//
//   • **The coach never reads `puzzle.solution`.** `NineGame.isError` — and the
//     coral highlight it drives — knows the answer, and `errorHighlight` is a
//     setting a player can switch off. A hint that pointed at coral would leak,
//     through the one surface a stuck player is most likely to open, exactly the
//     thing PRD-19 spent a release making the AX layer refuse to say. So a
//     contradiction here is a *peer clash* or a *dead cell*: both provable from
//     what is on screen, both identical with the setting on or off.
//   • **Nothing new goes inside `SolveStep`.** It lives in `GeneratedPuzzle.steps`
//     and therefore inside the golden-corpus hash, so the unit a deduction used
//     travels beside it in `CoachStep` rather than in it.
//
// Pure and deterministic: a map from a grid to advice, no clocks, no globals.
import Foundation
import CouchCore

/// One explained step, plus the units the explanation needs to name.
///
/// The unit indices follow `Sudoku.units`' fixed convention — `0..<9` rows,
/// `9..<18` columns, `18..<27` boxes — so the sentence layer can label them
/// without holding any solver state.
public struct CoachStep: Sendable, Equatable {
    public let step: SolveStep
    /// The unit that confines the pattern: for a hidden single, the unit in
    /// which the digit has exactly one home; for a box-line reduction, the
    /// *other* unit the spots share, which is the box when pointing and the
    /// line when claiming. Nil when the technique is not unit-scoped.
    public let patternUnit: Int?
    /// The unit every elimination lands in, when they share one. Nil for an
    /// X-wing (whose victims span two lines) and for techniques that eliminate
    /// nothing.
    public let targetUnit: Int?

    public init(step: SolveStep, patternUnit: Int?, targetUnit: Int?) {
        self.step = step
        self.patternUnit = patternUnit
        self.targetUnit = targetUnit
    }
}

/// What the coach has to say about a position.
public enum CoachAdvice: Sendable, Equatable {
    /// The next move the allowed techniques afford.
    case step(CoachStep)
    /// The board disagrees with itself at these cells — derived from the grid
    /// alone, never from the solution.
    case contradiction(cells: [Int])
    /// Consistent, unfinished, and nothing follows inside the band's ceiling.
    case exhausted
    /// Full and self-consistent.
    case solved
}

extension SudokuGrid {
    /// Filled cells whose value duplicates a peer's, ascending.
    ///
    /// `isConsistent` already answers the yes/no; the coach needs to point. Pure
    /// geometry — this never consults a solution, which is what makes it safe to
    /// speak while `showErrors` is off.
    public var conflictingCells: [Int] {
        var flagged = Set<Int>()
        for unit in Sudoku.units {
            var firstHome = [Int](repeating: -1, count: 10)
            for cell in unit where cells[cell] != 0 {
                let digit = cells[cell]
                if firstHome[digit] >= 0 {
                    flagged.insert(firstHome[digit])
                    flagged.insert(cell)
                } else {
                    firstHome[digit] = cell
                }
            }
        }
        return flagged.sorted()
    }
}

extension CandidateState {
    /// Empty cells with no candidate left. `isStuckDead` answers whether any
    /// exists; this says which, because the coach has to point at something.
    public var deadCells: [Int] {
        (0..<81).filter { values[$0] == 0 && candidates[$0] == 0 }
    }
}

extension LogicSolver {

    /// The coach's answer for a position.
    ///
    /// `context` is defaulted so the app layer never names it — PRD-23's channel
    /// seal greps `Sources/App`, `Sources/Widgets` and `Sources/Shared` for that
    /// symbol. When PRD-24 opens the channel the coach speaks variants for free.
    public static func advice(
        for grid: SudokuGrid,
        allowed: [Technique] = allTechniques,
        context: ConstraintContext = .classic
    ) -> CoachAdvice {
        // Order matters: a self-contradicting board can still yield a
        // technically valid-looking step, and offering one would be the coach
        // lying rather than declining.
        let clashes = grid.conflictingCells
        guard clashes.isEmpty else { return .contradiction(cells: clashes) }
        guard !grid.isFull else { return .solved }

        let state = CandidateState(grid: grid, context: context)
        let dead = state.deadCells
        guard dead.isEmpty else { return .contradiction(cells: dead) }

        guard let step = nextStep(in: state, allowed: allowed) else { return .exhausted }
        let target = targetUnit(for: step, in: state)
        return .step(CoachStep(
            step: step,
            patternUnit: patternUnit(for: step, in: state, target: target),
            targetUnit: target
        ))
    }

    /// The unit containing every pattern cell *and* every elimination. Exact for
    /// pairs and box-line reductions; nil for an X-wing, whose victims span two
    /// lines, and for techniques that eliminate nothing.
    private static func targetUnit(for step: SolveStep, in state: CandidateState) -> Int? {
        guard !step.eliminations.isEmpty else { return nil }
        let touched = Set(step.cells + step.eliminations.map(\.cell))
        return state.context.units.indices.first {
            Set(state.context.units[$0]).isSuperset(of: touched)
        }
    }

    /// The unit that confines the pattern.
    ///
    /// One rule covers both directions of a box-line reduction: the spots lie in
    /// exactly two units, and the eliminations are in one of them, so the other
    /// is the source. Pointing gives box → line, claiming gives line → box, and
    /// neither needs a special case.
    private static func patternUnit(
        for step: SolveStep, in state: CandidateState, target: Int?
    ) -> Int? {
        if step.technique == .hiddenSingle {
            guard let cell = step.cells.first, let digit = step.digits.first else { return nil }
            let bit = Sudoku.bit(digit)
            return state.context.unitsOfCell[cell].first { index in
                state.context.units[index].count(where: { state.candidates[$0] & bit != 0 }) == 1
            }
        }
        guard step.cells.count > 1 else { return nil }
        let pattern = Set(step.cells)
        return state.context.units.indices.first {
            $0 != target && Set(state.context.units[$0]).isSuperset(of: pattern)
        }
    }
}
```

No `NineGame` parameter: every sentence is derivable from the advice alone, and
a function that cannot see the game cannot leak the solution. That is a
type-level guarantee, not a convention — keep it.

**X-wing orientation** is derived in this layer, purely: an X-wing's four
corners always span two rows *and* two columns, so the corners cannot say which
was the base. The victims can — for a row-based X-wing every victim shares a
column with the corners.

```swift
let cols = Set(step.cells.map(Sudoku.col(of:)))
```

```swift
    /// rows, `9..<18` columns, `18..<27` boxes. Anything else — a variant
    /// unit, a bad index — returns "" and the caller's sentence falls back.
    public static func unitLabel(_ unitIndex: Int) -> String {
        switch unitIndex {
        case 0..<9:   return Phrase.row(unitIndex + 1)
        case 9..<18:  return Phrase.column(unitIndex - 9 + 1)
        case 18..<27: return Phrase.box(unitIndex - 18 + 1)
        default:      return ""
        }
    }

    /// The coach card's heading — the technique's name, or the state's.
    public static func coachTitle(_ advice: CoachAdvice) -> String {
        switch advice {
        case .step(let coach):  return coach.step.technique.displayName
        case .contradiction:    return Phrase.coachSlipTitle
        case .exhausted:        return Phrase.coachExhaustedTitle
        case .solved:           return Phrase.coachSolvedTitle
        }
    }

    /// The one sentence the card shows *and* VoiceOver speaks.
    ///
    /// Deliberately takes no `NineGame`: the coach must never be able to reach
    /// `puzzle.solution`, and the cheapest way to guarantee that is to give it
    /// nothing to reach it through.
    public static func coachSentence(_ advice: CoachAdvice) -> String {
        switch advice {
        case .contradiction: return Phrase.coachSlip
        case .exhausted:     return Phrase.coachExhausted
        case .solved:        return solvedAnnouncement
        case .step(let coach): return stepSentence(coach)
        }
    }

    private static func stepSentence(_ coach: CoachStep) -> String {
        let step = coach.step
        let digit = step.digits.first ?? 0
        switch step.technique {
        case .nakedSingle:
            guard let cell = step.cells.first else { return "" }
            return Phrase.coachNakedSingle(cellLabel(cell), digitWord(digit))

        case .hiddenSingle:
            let unit = unitLabel(coach.patternUnit ?? -1)
            guard !unit.isEmpty else {
                guard let cell = step.cells.first else { return "" }
                return Phrase.coachHiddenSingleFallback(cellLabel(cell), digitWord(digit))
            }
            return Phrase.coachHiddenSingle(unit, digitWord(digit))

        case .nakedPair:
            guard step.digits.count == 2 else { return "" }
            return Phrase.coachNakedPair(
                digitWordCapitalized(step.digits[0]), digitWord(step.digits[1]),
                unitLabel(coach.targetUnit ?? -1)
            )

        case .hiddenPair:
            guard step.digits.count == 2 else { return "" }
            return Phrase.coachHiddenPair(
                digitWordCapitalized(step.digits[0]), digitWord(step.digits[1]),
                unitLabel(coach.targetUnit ?? -1)
            )

        case .boxLineReduction:
            return Phrase.coachBoxLine(
                digitWord(digit),
                unitLabel(coach.patternUnit ?? -1),
                unitLabel(coach.targetUnit ?? -1)
            )

        case .xWing:
            // The four corners span two rows and two columns either way, so
            // they cannot say which axis was the base. The victims can: a
            // row-based X-wing eliminates down the shared columns.
            let cols = Set(step.cells.map(Sudoku.col(of:)))
            let victimCols = Set(step.eliminations.map { Sudoku.col(of: $0.cell) })
            let baseIsRow = victimCols.isSubset(of: cols)
            return Phrase.coachXWing(
                digitWordPlural(digit),
                base: baseIsRow ? Phrase.rowsWord : Phrase.columnsWord,
                cover: baseIsRow ? Phrase.columnsWord : Phrase.rowsWord,
                digitWord(digit)
            )

        default:
            // The four variant techniques. Naming them here would be a channel
            // leak (PRD-23); they are unreachable on a classic board anyway.
            return ""
        }
    }
```

```swift
    /// Returns false — pushing nothing — when the marks already match.
    @discardableResult
    public mutating func applyAutoNotes() -> Bool {
        let target = autoNoteMarks
        let snapshots = pencilSnapshots(changingTo: target)
        guard !snapshots.isEmpty else { return false }
        undoStack.append(NineMove(
            kind: .pencil, cell: snapshots[0].cell, digit: 0,
            previousEntry: entries[snapshots[0].cell], previousPencil: snapshots

        pencil = target

    /// Cells whose mask differs from `target`, snapshotted pre-change.
    private func pencilSnapshots(changingTo target: [UInt16]) -> [NineMove.PencilSnapshot] {
        (0..<81).compactMap { cell in
            pencil[cell] == target[cell] ? nil : .init(cell: cell, mask: pencil[cell])
        }
    }

    /// so the placement and the marks it implies undo together.

            kind: move.kind, cell: move.cell, digit: move.digit,
            previousEntry: move.previousEntry,
            previousPencil: move.previousPencil + extra

        undoStack.append(move)
        pencil = target
```

```swift
// CoachLedger.swift — what the coach remembers, per board (PRD-11 §6).
//
// Two things live here: how many hints a board has been shown, and whether auto
// notes is on for it. Neither gates anything — PRD-11 §3 rules hint quotas out
// forever, and the count exists so the stats drawer can be honest and so
// PRD-25's CoachProgress has something to build on.
//
// **This is its own `CouchStored` blob, keyed by library-entry id, and that is
// the whole design.** A field on `LibraryEntry` would be dropped by an older
// build's synthesized decode and erased on its next autosave 0.6 s later, over
// and over, for any mixed-version two-device player; field-level preservation
// was implemented, measured at 1515 ms against a 49 ms baseline, and reverted
// (EXECUTING-A-PRD §2). A sibling key costs nothing and cannot be clobbered.
//
// Local-only, never cloud-synced: like `undoCount`, a hint count is a property
// of the hand that played the board, not of the board (PRD-8 §2).
import Foundation

public struct CoachLedger: Codable, Equatable, Sendable {

    /// The most boards remembered at once. Pruning keeps the newest by
    /// insertion, so a heavy player's blob stays small and bounded.
    public static let capacity = 200

    /// What is remembered about one board.
    public struct Board: Codable, Equatable, Sendable {
        public var hints: Int
        public var autoNotes: Bool

        public init(hints: Int = 0, autoNotes: Bool = false) {
            self.hints = hints
            self.autoNotes = autoNotes
        }

        /// Tolerant per-field, so a future sibling field cannot take the blob
        /// down. Unknown keys are ignored by the container, as always.
        public init(from decoder: any Decoder) throws {
            guard let c = try? decoder.container(keyedBy: CodingKeys.self) else {
                self.init()
                return
            }
            hints = (try? c.decodeIfPresent(Int.self, forKey: .hints)) as? Int ?? 0
            autoNotes = (try? c.decodeIfPresent(Bool.self, forKey: .autoNotes)) as? Bool ?? false
        }
    }

    /// `LibraryEntry.id.uuidString` → record. Insertion order is not preserved
    /// by a dictionary, so `order` carries it for pruning.
    private var boards: [String: Board]
    /// Ids newest-last. Kept beside the dictionary rather than derived, because
    /// "which 200 to keep" needs an order a dictionary cannot give.
    private var order: [String]

    public init() {
        boards = [:]
        order = []
    }

    public var count: Int { boards.count }

    public func board(_ id: String) -> Board { boards[id] ?? Board() }

    public mutating func recordHint(_ id: String) {
        var record = board(id)
        record.hints += 1
        write(record, for: id)
    }

    public mutating func setAutoNotes(_ on: Bool, for id: String) {
        var record = board(id)
        record.autoNotes = on
        write(record, for: id)
    }

    /// Drop boards the library no longer holds, then trim to `capacity`.
    /// Called on every write from `AppModel`, so the blob tracks the library.
    public mutating func prune(to liveIDs: Set<String>) {
        boards = boards.filter { liveIDs.contains($0.key) }
        order = order.filter { boards[$0] != nil }
        while order.count > Self.capacity {
            boards.removeValue(forKey: order.removeFirst())
        }
    }

    private mutating func write(_ record: Board, for id: String) {
        if boards[id] == nil { order.append(id) }
        boards[id] = record
        while order.count > Self.capacity {
            let oldest = order.removeFirst()
            boards.removeValue(forKey: oldest)
        }
    }

    // `CouchStored` discards the entire blob when a decode throws, so this one
    // cannot: anything unreadable reads as "nothing remembered yet" instead of
    // taking the file down with it.
    public init(from decoder: any Decoder) throws {
        guard let c = try? decoder.container(keyedBy: CodingKeys.self),
              let stored = try? c.decodeIfPresent([String: Board].self, forKey: .boards) else {
            self.init()
            return
        }
        boards = stored ?? [:]
        order = (try? c.decodeIfPresent([String].self, forKey: .order)) as? [String] ?? []
        // Repair: any board with no place in the order goes to the end, so a
        // hand-edited or partially-written blob still prunes deterministically.
        let known = Set(order)
        order.append(contentsOf: boards.keys.filter { !known.contains($0) }.sorted())
        order = order.filter { boards[$0] != nil }
    }
}
```

```swift
    /// is no board. Capped at the board's own difficulty ceiling, so a Gentle
    /// board is never lectured about X-wings (PRD-11 §2.1).
    func requestCoachAdvice() -> CoachAdvice? {

        let advice = LogicSolver.advice(
            for: SudokuGrid(cells: (0..<81).map { game.entry(at: $0) }),
            allowed: game.puzzle.difficulty.allowedTechniques

        }
        return advice

    /// "the coach never places a digit" true: nothing here runs unprompted.
    /// A placement goes through the ordinary `place` path so wave, error rules,
    /// haptics and persistence are all standard.
    func applyCoachStep(_ coach: CoachStep) {
        if let placement = coach.step.placement {
            place(placement.digit, at: placement.cell)
            return

        guard solvedAt == nil, var g = game, !autoNotes else { return }

        where g.pencilDigits(at: elimination.cell).contains(elimination.digit) {
            changed = g.togglePencil(elimination.digit, at: elimination.cell) || changed
        }
        guard changed else { return }

        mutate(&ledger)
```

```swift
// CoachCard.swift — how a hint looks and reads (PRD-11 11a).
//
// Built to be reused: PRD-25 ("why must this be a seven?") narrates a *chain*
// of steps on the board, which is this same card and this same wash driven from
// an array instead of a single value. So the payload is one `CoachFocus` value
// rather than four `BoardView` parameters, and its role names are the
// base/cover/pivot/victim vocabulary PROGRAM-2.0 fixes for trace schema v2.
//
// Every string on screen comes from `BoardSpeech`, which is also what VoiceOver
// speaks — one sentence, one source, one thing for PRD-20 to localize.
#if os(iOS)
import SwiftUI
import CouchKit

/// The cells a hint lights, by the part they play in it.
struct CoachFocus: Equatable {
    /// The cells forming the pattern — an accent wash.
    let pattern: [Int]
    /// The cell the step resolves, if any — a stronger ring.
    let target: Int?
    /// Cells losing a candidate — a dimmer border.
    let victims: [Int]
    /// The digit under discussion, when there is exactly one.
    let digit: Int?

    /// Nil for `.solved`: the Afterglow owns that moment and nothing washes.
    init?(_ advice: CoachAdvice) {
        switch advice {
        case .solved:
            return nil
        case .exhausted:
            pattern = []
            target = nil
            victims = []
            digit = nil
        case .contradiction(let cells):
            pattern = cells
            target = nil
            victims = []
            digit = nil
        case .step(let coach):
            pattern = coach.step.cells
            target = coach.step.placement?.cell
            victims = Array(Set(coach.step.eliminations.map(\.cell))).sorted()
            digit = coach.step.digits.count == 1 ? coach.step.digits.first : nil
        }
    }
}

extension CoachAdvice {
    /// The card's one action, or nil when the coach has nothing to offer but
    /// the sentence. `autoNotes` suppresses `Mark it`: under PRD-11 §5 the
    /// marks are the machine's and the next placement recomputes them, so a
    /// button whose effect is erased one move later would be a button that lies.
    func actionTitle(autoNotes: Bool) -> String? {
        guard case .step(let coach) = self else { return nil }
        if coach.step.placement != nil { return Phrase.placeIt }
        guard !autoNotes, !coach.step.eliminations.isEmpty else { return nil }
        return Phrase.markIt
    }
}

    let advice: CoachAdvice
    let accent: Color
    let actionTitle: String?

                .foregroundStyle(accent)

                .font(CouchTypography.caption)
                .fixedSize(horizontal: false, vertical: true)
            if let actionTitle {

                    Text(actionTitle)
                        .font(.system(size: 15, weight: .semibold, design: .rounded))
                        .padding(.horizontal, 18)
                        .padding(.vertical, 9)
                        .couchGlass(in: Capsule())
                }
                .buttonStyle(.plain)
                .foregroundStyle(accent)
                .padding(.top, 2)
            }
        }
        .padding(.horizontal, 18)
        .padding(.vertical, 14)
        .frame(maxWidth: 360, alignment: .leading)
        .couchGlass(in: RoundedRectangle(cornerRadius: 22, style: .continuous))
        // One element, one sentence — VoiceOver reads the card as the thing it
        // is rather than as three fragments, and the button keeps its own.
        .accessibilityElement(children: .contain)
        .accessibilityLabel(
            "\(BoardSpeech.coachTitle(advice)). \(BoardSpeech.coachSentence(advice))"
        )
    }
}
```
