# PRD-22 "The Lens" — the remaining two-thirds

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish PRD-22 — measure the board's contrast on the *composited* glass with
an automated screenshot-sampling harness, retune the palette until the matrix clears
the floors, add an `accessibilityContrast` hairline variant, route the tutorial
through the theme system, and make the rose's petals genuinely lens the board with a
third Metal shader on the board Canvas's existing pipeline.

**Architecture:** Four independent thirds that share one new value type.
`RoseLens` (pure, in `Sources/Shared`, Linux-testable) becomes the single owner of
rose geometry — petal centres in board-local coordinates — consumed by *both*
`FlickRoseView` (which paints the petals) and `BoardView` (whose Canvas `layerEffect`
bends the digits under them). Contrast is measured by a Python harness that seeds
the already-frozen AX fixture board into a dedicated simulator, relaunches once per
`(theme, accent)` cell, screenshots, and samples composited pixels — the same shape
as `scripts/ax-snapshot.py`, whose simulator machinery it reuses wholesale.

**Tech Stack:** SwiftUI + Metal (`[[stitchable]]` `layerEffect`), XCTest/swift-testing,
Python 3 + `xcrun simctl` + `sim-use describe-ui`, GitHub Actions macOS runner.

- [ ] **Step 3: Write `RoseLens`**

`Sources/Shared` is compiled for Linux (Lane 1), so this file may not import SwiftUI

```swift
// RoseLens.swift — where the rose's petals are, in board-local points (PRD-22).
//
// This used to be six copies of the same arithmetic: TouchUI, MacUI, FirstRun,
// TutorialView (twice) and GameScreen each recomputed `126 * scale`, the
// `184 * scale` clamp and `centre + inset` by hand. That was survivable while
// only the petals read it. PRD-22 adds a second reader — the board Canvas's
// third layer effect bends the digits under each petal — and a lens that
// disagrees with the paint by four points is visible as a smear beside the
// glass rather than under it. So the arithmetic lives once, here, in
// Sources/Shared where Lane 1 can test it without a simulator.
//
// Coordinates are **board-local**: the origin is the Canvas's top-left, which
// is `inset` points inside the glass plane. `viewCentre` adds the inset back
// for `.position`, which measures in the padded frame.
import Foundation

/// Cell geometry, duplicated from `BoardMetrics` because that type lives in the
/// App layer (it needs CGPoint/CGRect for the accessibility frames) and this one
/// must compile on Linux. `BoardMetricsParityTests` pins the two together.
public enum BoardGeometry {
    public static func centre(of cell: Int, side: Double) -> (x: Double, y: Double) {
        let unit = side / 9
        return ((Double(cell % 9) + 0.5) * unit, (Double(cell / 9) + 0.5) * unit)
    }
}

/// Everything both the petals and the shader need to agree on.
public struct RoseLens: Equatable, Sendable {
    /// Petal diameter is `116 * scale` (88 in pencil mode); ring pitch is
    /// `126 * scale` (96). These four numbers are FlickRoseView's, unchanged.
    private static let petalSide = 116.0, pencilPetalSide = 88.0
    private static let ringPitch = 126.0, pencilRingPitch = 96.0
    /// Centre-to-centre drop from the bottom petal row to the erase glyph.
    private static let eraseDropFactor = 0.92
    /// Half the ring's full span, used to keep every petal on the plane.
    /// `126 + 116/2` — the non-pencil constants, deliberately, so the clamp does
    /// not move when the player toggles pencil mid-rose.
    private static let clampSpan = 184.0

    public let pencil: Bool
    public let scale: Double
    public let inset: Double
    /// Board-local centre of the ring, already clamped onto the plane.
    public let centre: (x: Double, y: Double)
    /// Distance from the eraser's centre to the ring's, or nil when absent.
    public let eraseDrop: Double?

    public init(
        cursor: Int,
        side: Double,
        inset: Double,
        pencil: Bool,
        showsErase: Bool,
        scale: Double
    ) {
        self.pencil = pencil
        self.scale = scale
        self.inset = inset
        let pitch = (pencil ? Self.pencilRingPitch : Self.ringPitch) * scale
        let erases = showsErase && !pencil
        self.eraseDrop = erases ? pitch + pitch * Self.eraseDropFactor : nil

        let raw = BoardGeometry.centre(of: cursor, side: side)
        let radius = Self.clampSpan * scale
        let frameSide = side + 2 * inset
        // The clamp works in *view* coordinates (the padded frame), which is
        // where the six call sites wrote it and where `.position` reads it.
        let bottomExtra = erases ? Self.ringPitch * scale * Self.eraseDropFactor : 0
        let x = min(max(raw.x + inset, radius - 6), frameSide - radius + 6)
        let y = min(max(raw.y + inset, radius - 6), frameSide - radius - bottomExtra + 6)
        self.centre = (x - inset, y - inset)
    }

    /// Ring pitch: centre-to-centre between neighbouring petals.
    public var spacing: Double {
        (pencil ? Self.pencilRingPitch : Self.ringPitch) * scale
    }

    /// Half a petal's drawn diameter — the lens radius the shader bends inside.
    public var petalRadius: Double {
        (pencil ? Self.pencilPetalSide : Self.petalSide) * scale / 2
    }

    /// Where `.position` puts the rose: the padded frame's coordinates.
    public var viewCentre: (x: Double, y: Double) {
        (centre.x + inset, centre.y + inset)
    }

    /// Digit 1…9 on the phone keypad: 1 2 3 / 4 5 6 / 7 8 9, 5 at the centre.
    public func petalCentre(digit: Int) -> (x: Double, y: Double) {
        let index = digit - 1
        let dx = Double(index % 3 - 1), dy = Double(index / 3 - 1)
        return (centre.x + dx * spacing, centre.y + dy * spacing)
    }

    /// Petals sized for fingers: a hair wider than a board cell, until the board
    /// is big enough that a cell-sized petal would be a dinner plate.
    public static func scale(forSide side: Double) -> Double {
        min(0.62, ((side / 9) * 1.15) / 116)
    }
}
```

#!/usr/bin/env python3
"""Measure Nine's board contrast on the *composited* glass (PRD-22).

`Tests/EngineTests/AppearancePaletteTests.swift` measures the raw theme
constants. The board does not draw those: it draws them through a
`couchGlass` plane that lifts the void, under an alternating box wash, at
whatever opacity the material resolves to on this OS. The gap between the two
numbers is the entire reason PRD-22 exists — a green palette test means "no
worse than what shipped", never "the board meets contrast".

So this harness measures pixels. For every (theme, accent) pair it seeds the
frozen AX-fixture board into a dedicated simulator, launches, screenshots, and
samples the composited surface:

  * **background**, per 3x3 box, as the median of the nine cells' median
    colours. Per box because the board's box borders *are* luminance steps —
    the bright boxes and the dim boxes are two different grounds, and the
    floor has to hold on the worse one.
  * **foreground**, per class, as the median of the most extreme decile of
    pixels inside each cell of that class, pooled across cells. The extreme
    decile is the glyph's core; the median of it survives one polluted cell
    (the cursor ring tints exactly one).

Three classes, three floors, from PRD-22: given digits >= 7:1, your entries
>= 4.5:1, the coral error marker >= 3:1. A fourth column, the rose petal's
glyph, is measured but scored against AA (4.5) — it exists because PRD-22
takes the opaque disc *off* the petals, and a petal you cannot read is not an
improvement.

    nine/scripts/contrast-harness.py                 # measure and gate
    nine/scripts/contrast-harness.py --record        # rewrite the matrix
    nine/scripts/contrast-harness.py --themes dark,ember --accents gold
    nine/scripts/contrast-harness.py --contrast      # + Increase Contrast pass

Determinism comes from the same four things `ax-snapshot.py` relies on — a
frozen board, a fixed device, fixed chrome state, a dedicated erased simulator
— plus one more: cell 40 is the resume cursor, and its accent ring is excluded
from every sample.
"""

The pixel work — kept dependency-free (no Pillow on a bare CI runner), reading the
PNG `simctl io screenshot` writes:

```python
def read_png(path):
    """Decode a truecolour PNG into (width, height, rows of (r,g,b) bytes).

    `simctl io screenshot` writes 8-bit RGBA, non-interlaced. Rather than take a
    Pillow dependency on a runner that has none, this handles exactly that shape
    and refuses anything else loudly — a silent wrong decode would be measured
    and believed."""
    with open(path, "rb") as handle:
        data = handle.read()
    if data[:8] != b"\x89PNG\r\n\x1a\n":
        sys.exit("%s is not a PNG" % path)
    pos, idat, width, height, depth, colour = 8, [], None, None, None, None
    while pos < len(data):
        length = struct.unpack(">I", data[pos:pos + 4])[0]
        kind = data[pos + 4:pos + 8]
        body = data[pos + 8:pos + 8 + length]
        if kind == b"IHDR":
            width, height, depth, colour = struct.unpack(">IIBB", body[:10])
        elif kind == b"IDAT":
            idat.append(body)
        elif kind == b"IEND":
            break
        pos += length + 12
    if depth != 8 or colour not in (2, 6):
        sys.exit("unexpected PNG shape (depth %s, colour type %s) — this harness "
                 "decodes 8-bit RGB/RGBA only" % (depth, colour))
    channels = 3 if colour == 2 else 4
    raw = zlib.decompress(b"".join(idat))
    stride = width * channels
    out, prior, pos = [], bytearray(stride), 0
    for _ in range(height):
        filter_type = raw[pos]; pos += 1
        line = bytearray(raw[pos:pos + stride]); pos += stride
        unfilter(filter_type, line, prior, channels)
        out.append(bytes(line))
        prior = line
    return width, height, out, channels


def unfilter(kind, line, prior, bpp):
    """The five PNG line filters, in place (RFC 2083 §6)."""
    if kind == 0:
        return
    for i in range(len(line)):
        a = line[i - bpp] if i >= bpp else 0
        b = prior[i]
        c = prior[i - bpp] if i >= bpp else 0
        if kind == 1:   line[i] = (line[i] + a) & 0xFF
        elif kind == 2: line[i] = (line[i] + b) & 0xFF
        elif kind == 3: line[i] = (line[i] + (a + b) // 2) & 0xFF
        elif kind == 4:
            p = a + b - c
            pa, pb, pc = abs(p - a), abs(p - b), abs(p - c)
            pr = a if (pa <= pb and pa <= pc) else (b if pb <= pc else c)
            line[i] = (line[i] + pr) & 0xFF
        else:
            sys.exit("unknown PNG filter %d" % kind)
```

Sampling and the WCAG math:

```python
def linearize(channel):
    c = channel / 255.0
    return c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4


def luminance(rgb):
    r, g, b = rgb
    return 0.2126 * linearize(r) + 0.7152 * linearize(g) + 0.0722 * linearize(b)


def contrast(a, b):
    x, y = luminance(a), luminance(b)
    return (max(x, y) + 0.05) / (min(x, y) + 0.05)


def pixels(image, rect, inset):
    """Every pixel inside `rect`, shrunk by `inset` of its side.

    The inset is not decoration: a cell's outer few points carry the hairline
    separator, the neighbouring box's wash and — on the cursor cell — an accent
    ring. Sampling them would measure the grid, not the digit."""
    width, height, rows, channels = image
    x0 = int(rect["x"] + rect["width"] * inset)
    x1 = int(rect["x"] + rect["width"] * (1 - inset))
    y0 = int(rect["y"] + rect["height"] * inset)
    y1 = int(rect["y"] + rect["height"] * (1 - inset))
    out = []
    for y in range(max(0, y0), min(height, y1)):
        row = rows[y]
        for x in range(max(0, x0), min(width, x1)):
            i = x * channels
            out.append((row[i], row[i + 1], row[i + 2]))
    return out


def median_rgb(samples):
    if not samples:
        return None
    return tuple(sorted(s[c] for s in samples)[len(samples) // 2] for c in range(3))


def ground(samples):
    """The cell's background: the median pixel. A digit covers well under half
    a cell, so the median is background by construction — and unlike the mode it
    does not care that the glass carries a gradient."""
    return median_rgb(samples)


def glyph_core(samples, base, fraction=0.10):
    """The drawn ink: the median of the decile furthest in luminance from the
    ground. Antialiasing means the extreme *pixel* is noise; the extreme decile
    is the stroke's core, and a median of it is stable."""
    if not samples:
        return None
    base_l = luminance(base)
    ranked = sorted(samples, key=lambda p: -abs(luminance(p) - base_l))
    take = max(24, int(len(ranked) * fraction))
    return median_rgb(ranked[:take])
```

def classify(entries, scale):
    """Cell frames in *pixels*, grouped by what the board is drawing in them."""
    classes = {"givens": [], "entries": [], "coral": []}
    boxes = {}
    for entry in entries:
        label, value = entry.get("label", ""), entry.get("value", "")
        if not label.startswith("Row "):
            continue
        row = int(label.split("Row ")[1].split(",")[0]) - 1
        col = int(label.split("column ")[1]) - 1
        index = row * 9 + col
        rect = {k: entry["frame"][k] * scale
                for k in ("x", "y", "width", "height")}
        boxes.setdefault((row // 3) * 3 + col // 3, []).append(rect)
        if index == CURSOR_CELL:

        if value.endswith(", given"):     classes["givens"].append(rect)
        elif value.endswith(", wrong"):   classes["coral"].append(rect)
        elif value and value[0].isdigit(): classes["entries"].append(rect)
    return classes, boxes

and the per-cell measurement:

```python
def measure(image, classes, boxes):
    """One (theme, accent) cell of the matrix.

    Grounds are per box, foregrounds are pooled across every cell of a class,
    and the reported ratio is the worst pairing — because a player reading a
    given in box 5 has no idea box 5 happens to be the bright one."""
    grounds = {}
    for box, rects in boxes.items():
        per_cell = [ground(pixels(image, r, 0.22)) for r in rects]
        grounds[box] = median_rgb([c for c in per_cell if c])
    worst_ground = grounds  # every ground is a candidate; see below

    out = {}
    for name, rects in classes.items():
        if not rects:
            out[name] = None
            continue
        cores = []
        for rect in rects:
            samples = pixels(image, rect, 0.18)
            local = ground(samples)
            core = glyph_core(samples, local)
            if core:
                cores.append(core)
        ink = median_rgb(cores)
        out[name] = min(contrast(ink, g) for g in worst_ground.values())
    return out
```

- [ ] **Step 1: Write the shader**

Nine lenses from five uniforms, because the petals *are* a rigid 3×3 grid — passing
nine centres would let the paint and the bend disagree, and the grid is exactly what
`RoseLens` already guarantees.

```metal
/// Per-petal refraction (PRD-22). The rose's petals are true glass: this bends
/// and magnifies the board's own drawing under each one, so a digit beneath a
/// petal reads as seen *through* it. SwiftUI draws only the glyph and the rim
/// above — a `layerEffect` cannot sample behind its own layer, so glassifying
/// the petal views was never going to work; bending the layer underneath is.
///
/// The nine centres are derived here rather than passed, from the same ring
/// pitch `RoseLens` hands the petals, so the bend cannot drift from the paint.
/// `bloom` scales the ring with the petals' own spring (0 = closed, 1 = open).
[[stitchable]] half4 rosePetalLens(
    float2 position,
    SwiftUI::Layer layer,
    float2 centre,
    float spacing,
    float radius,
    float magnification,
    float bloom,
    float eraseDrop
) {
    if (bloom <= 0.001) { return layer.sample(position); }

    float pitch = spacing * bloom;
    float r = radius * bloom;

    // Nearest petal centre on the 3x3 grid, plus the optional eraser below it.
    float2 local = (position - centre) / pitch;
    float2 snapped = clamp(round(local), float2(-1.0), float2(1.0));
    float2 best = centre + snapped * pitch;
    float bestDist = distance(position, best);

    if (eraseDrop > 0.0) {
        float2 eraser = centre + float2(0.0, eraseDrop * bloom);
        float d = distance(position, eraser);
        if (d < bestDist) { best = eraser; bestDist = d; }
    }

    if (bestDist >= r) { return layer.sample(position); }

    float2 delta = position - best;
    float t = bestDist / r;                       // 0 at the centre, 1 at the rim

    // A spherical lens: the core magnifies uniformly (sample from a smaller
    // neighbourhood), and the last quarter compresses hard the way a real
    // meniscus does — that compressed band is what makes glass read as glass
    // rather than as a zoom.
    float rim = smoothstep(0.74, 1.0, t);
    float scale = mix(1.0 / magnification, 1.0 + 0.85, rim);
    float2 sampled = best + delta * scale;
    half4 color = layer.sample(sampled);

    // A thin specular arc just inside the rim, scaled by alpha so it rides the
    // drawn content and never fogs empty board (the Afterglow rule).
    float arc = exp(-(t - 0.93) * (t - 0.93) / (2.0 * 0.045 * 0.045));
    color.rgb += half(arc * 0.16) * color.a;
    return color;
}
```
